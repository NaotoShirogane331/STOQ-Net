# Historical source records

These records describe the repository's earlier source synchronizations,
configuration checks and synthetic interface tests. They are retained for
provenance, separately from the current [paper results](../../paper_results/README.md).
Their visibility statements, file inventories, hashes and test counts apply
to their recorded versions. They are not a current inventory or verification
of this paper companion and do not establish paper-performance reproduction.
